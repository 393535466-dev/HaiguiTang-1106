# 海龟汤单人语音版

微信内单人海龟汤体验版。按住说话，松手后确认或修改识别文字，再提交给 AI 裁判；也可直接打字。先做三道固定题，验证完整解谜体验。

## 第一版范围

- 三道原创日常轻悬疑，固定事实、三级提示和独立猜底标准。
- 语音转写后由玩家确认，主持人以文字给出「是」「不是」「无关」。澄清和未设定细节显示为提示。
- 问答记录、草稿恢复、主动揭底、清空及题目反馈。首轮试玩暂定每局 30 次有效提问，用完自动揭底。
- 服务端鉴权、请求去重、调用限额、超时状态和录音清理。
- 可跳过的四步操作练习：读汤面、亲自输入并确认提问、查看提示、输入并提交猜底。文字练习离线可用；微信语音练习接入云端转写，核对后才发送。练习判词为预设示例，不调用裁判、不消耗正式局提问次数；语音仍按实际识别量计费和计入配额。

第一次试玩采用单人小程序。单人真机试玩通过后，好友房和排行榜作为同一批功能开发。当前使用原生小程序页面作为候选实现，须结合真实账号核对可用类目、运行时和体验资格。

## 界面与 AI 的落地方式

参考[汤局上手教程](https://onlinesoup.ai0506.com/onboarding)的逐步操作和明确入口，沿用本项目的视觉、原创故事及玩法规则。首页提供「第一次玩？跟着做一遍」入口，游戏内的「···」菜单也可以打开练习，返回后继续原局。玩家在提问、猜底两步亲自输入，示例按钮只填入可编辑草稿，不自动发送。提交后显示玩家原话和示例回复；预设范围之外的文字明确说明未判定，不根据关键词编造答案。练习固定标明示例性质，不把示例答案当作真实 AI 能力展示。

正式流程为选题 → 读汤面 → 提问 → 必要时看提示 → 完整猜底 → 揭晓和再来一局。提问和猜底由玩家选择操作模式，AI 在对应模式内理解文本、核对题目事实；不明确时澄清，不能用聊天猜测代替显式操作。语音先转文字并由玩家确认；提示来自审核过的固定题库；裁判结果以文字展示。

当前先交付微信小程序，H5 作为后续可选入口。本地浏览器预览用于验证同一批小程序页面和文字操作，不支持录音转写，并非接入真实模型的已上线 H5。微信语音练习须部署最新云函数、填写账号配置后真机验证。正式 H5 还需接入真实用户身份、后端鉴权、录音权限和部署，不能直接将本地测试服务公开。

好友房在单人试玩通过后与排行榜一起实现。界面采用顶部题目与轮次、共享消息记录、底部明确操作入口；讨论不调用 AI，正式提问和猜底由当前玩家确认后提交。具体同步和交接规则见[验收清单](docs/ACCEPTANCE.md)。

## 先运行本地检查

需要 Node.js 20 或更高版本。从仓库根目录执行：

```sh
npm test
npm run check
npm run preflight
npm run preview
```

`preview` 启动后按终端显示的本机地址打开。浏览器预览用于界面检查，不代替微信真机录音。隔离的服务端测试使用显式 fake provider，不会证明真实语音识别或大模型准确率。

没有真实 AppID、云环境和百炼 Key 时，可以先检查代码和界面，不能完成真实联调。未配置或未显式启用时应展示待配置状态，生产入口不会自动伪造 AI 答案。

## 导入微信开发者工具

1. 先复制 `miniprogram/config.example.js` 为 `miniprogram/config.local.js`（可先保持空），再使用[官方稳定版工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入仓库根目录，填写本人账号的真实 AppID。
2. 从该 AppID 项目的「云开发」入口创建或关联环境。
3. 在被 Git 忽略的 `miniprogram/config.local.js` 填写云环境 ID。
4. 按[部署说明](docs/DEPLOY.md)创建私有集合、配置云存储并部署 `game` 云函数。
5. 百炼密钥只放云端受控配置。先保持 `GAME_ENABLED=false`，完成真实权限、隐私及内容处理检查后再开启调用。

账号注册、扫码和充值由用户完成；代码、配置协助、题库和测试由开发方处理。不要在聊天、前端或 Git 中提交 API Key、AppSecret 或阿里云主账号 AccessKey。

## 架构

```text
miniprogram/                   微信原生页面、录音、草稿、受控公开数据
cloudfunctions/game/           单个 game 云函数及服务端私有题库
  data/puzzles.js              汤面、汤底、事实、提示、人工测试预期
  lib/                        服务、存储、模型与音频适配
tests/                         无真实外呼的自动测试
docs/                          接口、部署、内容与验收说明
```

主链路为录音上传、同步 ASR、文字确认、服务端判题、界面显示文字。客户端不直连模型、不保存汤底。数据库由云函数访问，录音存储采用仅创建者可读写的安全规则；服务端另行校验已登记文件归属和实际音频，凭管理权限下载及删除。

## 费用与验收边界

基准假设每局 32 次调用，每段录音平均 6 秒，每次模型输入 2,000、输出 50 token。按北京地域 `qwen3-asr-flash` 0.00022 元/秒、`qwen-flash` 输入 0.15 元/百万 token 与输出 1.5 元/百万 token 测算：

```text
基础调用费  192 × 0.00022 + 32 × (2000 × 0.15 + 50 × 1.5) ÷ 1000000
          = 0.05424 元/局
加30%余量 = 0.070512 元/局
```

初期按每局 0.08 至 0.10 元预留语音与模型费用，另算云资源。100 元是小规模试玩预算，不是整月账单硬上限。长局、更多录音、重试和更换模型会改变费用，免费额度不计入长期预算。价格核查日期为 2026-11-06，接入时再核对[语音价格](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash)和[文字模型价格](https://help.aliyun.com/zh/model-studio/qwen-flash)。

3 至 5 秒是正常网络下的系统等待目标，不是实测或 SLA。真实录音、模型问答、跨端表现和平台权限按[验收清单](docs/ACCEPTANCE.md)逐项记录；未测项不能写成已达标。
