# 海龟汤语音版 · 单人和好友同玩

海龟汤体验版，支持单人和 2～6 人好友房。按住说话，松手后确认或修改识别文字，再提交给 AI 裁判；也可直接打字。已接入难度 1–10 的十篇混合题材新剧本，并保留三道原有题。


## 2026-11-10 H5 发布方式

GitHub `main` 连接 Vercel 项目 `haiguitang1106`。`npm run build:h5` 只将白名单页面和公开素材导出到 `dist`，私有题库、密钥和玩家存档不进入网页目录。Vercel 的四个 API 路由通过服务端 `HGT_UPSTREAM_URL` 转发到原有邀请网关，邀请凭证只存于加密环境变量。

本次按用户确认采用 **Vercel 页面 + 本机游戏服务**：页面独立托管，AI、房间、排行榜和存档仍在本机。电脑须持续开机联网，预览服务、网关和 Tailscale Funnel 8443 均需运行；后端邀请到期或本机离线时，页面仍能打开，但不能继续游戏。这不是独立云端后端，不需要把百炼 Key 复制到 Vercel。后续迁移需云端持久存储、音频短期存储、身份及内容治理，不得用无状态函数内存替代跨实例房间。

当前视觉以代码为准：米白细花边剧本卡、欧式古典配图；图标顺序为排行榜、设置、我的。首页中英文上下排列，新手试玩单独入口。汤面、对话、提问/猜底切换和草稿合并于一个纸面中。后续旧日期的验证段落是历史记录。

## 第一版范围

- 十篇分级原创剧本（六篇悬疑、两篇温情、两篇无厘头）和三道原有题，每题都有固定事实、三级提示及独立猜底标准；难度等级待玩家盲测校准。
- 语音转写后由玩家确认，主持人给出文字判词，可开启自然女声播报读题、主持回应和揭晓结果。澄清和未设定细节显示为提示。
- 问答记录、草稿恢复、主动揭底、清空及题目反馈。首轮试玩暂定每局 30 次有效提问，用完自动揭底。
- 服务端鉴权、请求去重、调用限额、超时状态和录音清理。
- 可跳过的四步操作练习：读汤面、亲自输入并确认提问、查看提示、输入并提交猜底。练习与正式游戏使用同一套真实 AI 裁判，按玩家原话判题；独立会话不消耗原正式局的提问次数，但模型和转写均计费、计入配额。

2026-11-08，用户确认单人试玩可以，授权进入好友房和排行榜阶段；同时确认账号尚未准备，本轮先完成本机多人试玩。当前使用原生小程序页面作为候选实现，须结合真实账号核对可用类目、运行时和体验资格。

## 界面与 AI 的落地方式

参考[汤局上手教程](https://onlinesoup.ai0506.com/onboarding)的逐步操作和明确入口，沿用本项目的视觉、原创故事及玩法规则。首页提供「新手试玩」入口，游戏内的「···」菜单也可以打开练习，返回后继续原局。玩家在提问、猜底两步亲自输入，示例按钮只填入可编辑草稿，不自动发送。提交后显示玩家原话和真实模型判词。先识别问句意图，再依据私有题目事实判断；开放问法、多个问题和指代不明时给出具体澄清提示。未配置 AI 时在读题页提示，不能进入提问后才发现无法判断。

正式流程为选题 → 读汤面 → 提问 → 必要时看提示 → 完整猜底 → 揭晓和再来一局。提问和猜底由玩家选择操作模式，AI 在对应模式内理解文本、核对题目事实；不明确时澄清，不能用聊天猜测代替显式操作。语音先转文字并由玩家确认；提示来自审核过的固定题库；文字判词可搭配 AI 合成女声。首次点击「开启自然人声」或「听题」，开启后自动播报新回应及结果；录音、关声音或离开页面时立即停止。

当前先交付微信小程序，浏览器已接入真实文字 AI、短录音转写和自然女声播报，用于验证同一批小程序页面。新增带邀请凭证的临时 HTTPS 手机入口，供少量设备联测，不是正式运营部署。微信语音练习须部署最新云函数、填写账号配置后真机验证。正式 H5 仍需持久账号体系、云端运行及手机权限验收；不能直接将本地测试服务公开。

好友房和排行榜在同一版实现。界面采用顶部题目与轮次、共享消息记录、底部明确操作入口；讨论不调用裁判模型，正式提问和猜底由当前玩家确认后提交。具体规则见[好友房与排行榜说明](docs/MULTIPLAYER.md)。

## 前端设计与浏览器验收

首页文案上移并删除副标语，眼睛每轮眨一次后停顿。通用中文正文使用源雲明體丹（源云明宋体）Regular，标题与点击文案保留既定手写字体。单人和好友选题共用横向滑动的古纸卡片，13 个剧本各有独立古典油画封面，画面与简介以真实纸边透明遮罩衔接；支持滑动、邻卡点击和左右按钮，点当前卡片可开始单人故事或创建好友房，滑动和邻卡点击仅切换选题，原开始按钮也保留。卡片整体降低 30% 饱和度。顶部统一为我的、排行榜、设置三个入口，支持修改昵称和设置主持人声音。

首页采用深黑粗纸撕口与单只版画眼睛，Logo 使用用户确认的红色与亮蓝色。品牌文字统一为「海龟汤」，使用用户指定的品如手写体与青柳隶书体；主要文案采用较细的品如笔画。进入游戏和后续大卡片为米黄色撕纸，页面统一黑色粗纸背景；进入游戏为小幅撕纸按钮，首次试玩入口位于它下方，首页去掉能力说明。眼睛每轮眨一次后停顿约五秒，系统减少动态效果时静止。入口为首页 → 选择玩法 → 单人选题或好友大厅，一屏一个主要任务。整页固定，汤面、玩家问题和 AI 回答合并到一张可内部滚动的大纸面；人声控制与次数放在纸面上方，录音/发送改为深色背景上的白字；选题、排行榜和隐私说明通过按钮翻页。好友房每轮 45 秒，自己的讨论、他人消息与 AI 判词分开呈现；主要输入按钮按手机触控尺寸设计。桌面居中展示竖屏应用，常规手机竖屏铺满；较矮窗口按可用高度限制宽度，避免标题与眼睛重叠。首次加载有可见提示，脚本或图片失败可手动重试。

`npm run test:browser-design` 检查 320/390/430/488/700/900/1320 宽度、慢加载及失败重试、字体/图片加载、单次眨眼和减少动态效果、首次试玩完整返回路径、分步路由和浏览器前进/返回、六人房间、加入流程、倒计时期间中文输入、分页榜单/隐私、空状态及未配置界面。使用与其他浏览器检查相同的 Playwright/Chromium 环境，`PREVIEW_SCREENSHOT_DIR` 可指定截图目录。它使用固定裁判，不调用付费模型；微信真机键盘、录音权限与云端仍需独立验收。网页眼部素材采用压缩副本，微信主包体积与资源分包须在原生发布前处理。新增卡片完整提示词和资源路径见 [剧本配图记录](docs/story-card-assets.json)，横向选择回归用 `npm run test:browser-carousel`。源云字体按字符分片，新增首屏字体包约 400 KB；全字集约 15.6 MB 按需读取，原生交付仍需托管或资源拆分。当前字体来源、字形回退、素材和导出方式见 [纸面主题素材记录](docs/paper-theme-assets.txt)。原字体共约 10.46 MB，H5 使用 HTTP 无损传输压缩；微信原生发布前须另外安排字体托管/分包并真机核验，当前不能直接把完整字体主包作为正式发布包。生成记录见 [原始素材提示词](docs/brand-assets-prompts.txt) 和 [首页动效素材记录](docs/home-motion-assets.txt)。

## 先运行本地检查

需要 Node.js 20 或更高版本。从仓库根目录执行：

```sh
npm test
npm run check
npm run preflight
npm run preview
```

`preview` 默认走真实服务。在仓库根目录创建被 Git 忽略的 `.env.preview.local`（权限建议 600），只在该文件填入密钥：

```dotenv
DASHSCOPE_API_KEY=在本机填写北京地域的Key
GAME_ENABLED=true
LLM_MODEL=qwen-plus
ASR_MODEL=qwen3-asr-flash
TTS_MODEL=qwen3-tts-flash
TTS_VOICE=Serena
```

运行后打开 <http://127.0.0.1:18875/>，从「新手试玩」开始。保存配置后可重新检查连接；不会把 Key 放到浏览器。每次确认提问/猜底会计费，查看提示和查询原结果不重复调用模型。开发服务仅绑定本机，对局、积分及计量保存在 `.preview-data/preview-state.json`（Git 忽略、文件权限 600），重启可恢复；它仍不是平台账单硬上限。此服务不接微信内容安全审核，仅供开发者本机联调；上线使用云函数的鉴权、审核和持久配额。

仅检查布局时显式用 `npm run preview:fixture`；页面会标明固定裁判。未配置真实模型绝不自动切到测试答案。`npm test` 全部使用隔离替身，不产生外呼。真实回归另用 `npm run eval:ai`（练习题 24 次）或 `npm run eval:ai -- --full`（当前共 217 次，包括练习题、十篇新剧本和三篇旧题）。`--collection=workshop-20261109` 可只复测新剧本（121 次）。该脚本直接调用模型，不走游戏配额；结果存于被忽略的 `.preview-data/`，仅在需要复测时运行。

2026-11-07：优化模糊指代和相关性判断后，`qwen-plus` 非思考模式的 96 条固定样本全部符合预期，其中猜底 16/16。详见[真实验证记录](docs/IMPLEMENTATION.md)。这不是整体产品准确率，也不代替微信真机录音验收。

没有真实 AppID、云环境时，可先用本机 Key 验证文字 AI，微信录音和云端权限仍无法完成联调。未配置或未显式启用时应展示待配置状态，生产入口不会自动伪造 AI 答案。

## 生成微信体验交付包

账号准备后可执行 `npm run prepare:wechat -- --appid 真实AppID --env 真实云环境ID`，参数仅写入生成的副本。默认不读取私有账号配置，未提供时保持待配置状态；密钥仍只填云端。用 `npm run preflight -- --project 交付目录` 检查交付文件与账号字段，格式通过不代表云端连接或真机验收通过。

下一步按 [双人真机验收表](docs/DEVICE-TEST.md) 执行。账号、登录和真实手机尚未准备时，不能生成有效体验二维码。

## 架构

```text
miniprogram/                   微信原生页面、录音、草稿、受控公开数据
cloudfunctions/game/           单个 game 云函数及服务端私有题库
  data/puzzles.js              正式题目录、旧题及人工测试预期
  data/workshop-20261109.json   十篇分级剧本的私有事实和判题样本
  data/tutorial.js             独立练习题的私有事实和测试预期
  lib/                        服务、存储、模型与音频适配
tests/                         无真实外呼的自动测试
docs/                          接口、部署、内容与验收说明
```

主链路为录音上传、同步 ASR、文字确认、服务端判题、显示文字和可选人声播报。浏览器使用锁定版本的 MIT 开源 [Recorder](https://github.com/xiangyuecn/Recorder) 录制单声道 16kHz WAV；微信原生录音仍使用 MP3。客户端不直连模型、不保存汤底。数据库由云函数访问，录音存储采用仅创建者可读写的安全规则；服务端另行校验已登记文件归属和实际音频，凭管理权限下载及删除。

## 费用与验收边界

基准假设每局 32 次调用，每段录音平均 6 秒，每次模型输入 2,000、输出 50 token。按北京地域 `qwen3-asr-flash` 0.00022 元/秒、`qwen-plus` 非思考模式输入 0.8 元/百万 token 与输出 2 元/百万 token 测算：

```text
基础调用费  192 × 0.00022 + 32 × (2000 × 0.8 + 50 × 2) ÷ 1000000
          = 0.09664 元/局
加30%余量 = 0.125632 元/局
```

上述为识别和裁判费用。新增自然人声按 `qwen3-tts-flash` 北京价格 0.8 元/万字符测算：假设每局读题、判词和揭晓合计 800 字且全部重新合成，增加 0.064 元；总基础费用 0.16064 元，加 30% 余量约 0.2088 元。全语音版暂按每局 0.21 至 0.25 元预留，云资源另算。重复内容会复用合成结果，但冷启动、缓存过期或重启可能重新合成，预算不预扣缓存收益。参见[人声合成价格](https://help.aliyun.com/zh/model-studio/qwen3-tts-flash)。100 元是小规模试玩预算，不是整月账单硬上限。长局、更多录音、重试和更换模型会改变费用，免费额度不计入长期预算。价格核查日期为 2026-11-07，运营时继续核对[语音价格](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash)和[文字模型价格](https://help.aliyun.com/zh/model-studio/qwen-plus)。

3 至 5 秒是正常网络下的系统等待目标，不是实测或 SLA。真实录音、模型问答、跨端表现和平台权限按[验收清单](docs/ACCEPTANCE.md)逐项记录；未测项不能写成已达标。

## 本机语音试玩

打开 Chrome 等支持麦克风的浏览器，先同意语音用途说明和麦克风权限，再按住说话、松手转写。首次授权时如果已经松手，再按住一次开始录音。文字核对后才提交 AI。人声默认关闭，点「听题」或「开启自然人声」后开启；可随时关闭或重播。若浏览器拦截自动播放，点击重播；若麦克风被拒，在地址栏网站权限中开启，打字始终可用。

本机录音只保存在内存，成功识别或取消后清理；未完成文件最多保留 10 分钟并按分钟清理，服务重启后消失。缓存的主持音频只含固定故事和主持判词，不朗读玩家任意输入。进行中的游戏不能获取汤底声音。微信真机和嵌入浏览器的系统权限仍需各自测试。

## 本机多人试玩

主玩家打开 <http://127.0.0.1:18875/#/pages/room/index>，填写昵称并创建房间。第二名玩家在独立窗口打开 <http://127.0.0.1:18875/?guest=1#/pages/room/index>，输入另一昵称和六位房间号加入；也可点击侧栏的访客入口。至少两人入座后，由房主开始。

大家都能讨论，轮到的人向 AI 提问或猜底；每轮 45 秒，约每 2 秒同步。好友局共同得分，每题只有首次开局计分。排行榜在首页可进入。访客窗口刷新可继续，关闭后不保证能恢复同一访客身份。

这些 localhost 入口只能在当前电脑使用。手机联测使用下方的独立邀请入口；微信账号仍待准备。详细规则、已测项和边界见 [MULTIPLAYER.md](docs/MULTIPLAYER.md)。

## 手机外网测试

`scripts/mobile-preview.js` 是本机预览服务之前的独立网关，仅监听 `127.0.0.1:18876`。本次通过现有 Tailscale Funnel 的独立 HTTPS 8443 端口转发，不覆盖其他端口上的服务。运行配置位于被 Git 忽略的 `.preview-data/mobile-access.json`，字段为 `publicOrigin`、随机 `accessToken`、毫秒时间戳 `expiresAt`、`port` 和 `upstreamPort`。邀请凭证不提交到仓库。

首次从完整 `/invite/<凭证>` 链接进入，网关设置 Secure/HttpOnly cookie 后跳转到首页；本轮邀请有效 48 小时。外网浏览器自动生成独立玩家身份并保存在该浏览器中，刷新、关闭后再打开可以继续。两台手机使用同一邀请链接，一台创建好友房，另一台填写不同昵称及六位房间号加入。建议使用 Safari/Chrome；录音先授权、转文字并确认后发送。

网关拒绝过期/无邀请访问、跨站请求、无玩家身份的业务请求，以及私有文件路径。后端仍保留原有调用限额。主服务和网关必须持续运行，电脑保持开机联网且不要合盖；暂停本次入口可执行 `tailscale funnel --https=8443 off`，不会关闭原有 443 端口。更换邀请时更新私有配置并重启网关，旧 cookie 随之失效。临时 H5 联测不等于微信发布或真机验收通过。
