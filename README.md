# 海龟汤单人语音版

微信内单人海龟汤体验版。按住说话，松手后确认或修改识别文字，再提交给 AI 裁判；也可直接打字。先做三道固定题，验证完整解谜体验。

## 第一版范围

- 三道原创日常轻悬疑，固定事实、三级提示和独立猜底标准。
- 语音转写后由玩家确认，主持人给出文字判词，可开启自然女声播报读题、主持回应和揭晓结果。澄清和未设定细节显示为提示。
- 问答记录、草稿恢复、主动揭底、清空及题目反馈。首轮试玩暂定每局 30 次有效提问，用完自动揭底。
- 服务端鉴权、请求去重、调用限额、超时状态和录音清理。
- 可跳过的四步操作练习：读汤面、亲自输入并确认提问、查看提示、输入并提交猜底。练习与正式游戏使用同一套真实 AI 裁判，按玩家原话判题；独立会话不消耗原正式局的提问次数，但模型和转写均计费、计入配额。

第一次试玩采用单人小程序。单人真机试玩通过后，好友房和排行榜作为同一批功能开发。当前使用原生小程序页面作为候选实现，须结合真实账号核对可用类目、运行时和体验资格。

## 界面与 AI 的落地方式

参考[汤局上手教程](https://onlinesoup.ai0506.com/onboarding)的逐步操作和明确入口，沿用本项目的视觉、原创故事及玩法规则。首页提供「第一次玩？跟着做一遍」入口，游戏内的「···」菜单也可以打开练习，返回后继续原局。玩家在提问、猜底两步亲自输入，示例按钮只填入可编辑草稿，不自动发送。提交后显示玩家原话和真实模型判词。先识别问句意图，再依据私有题目事实判断；开放问法、多个问题和指代不明时给出具体澄清提示。未配置 AI 时在读题页提示，不能进入提问后才发现无法判断。

正式流程为选题 → 读汤面 → 提问 → 必要时看提示 → 完整猜底 → 揭晓和再来一局。提问和猜底由玩家选择操作模式，AI 在对应模式内理解文本、核对题目事实；不明确时澄清，不能用聊天猜测代替显式操作。语音先转文字并由玩家确认；提示来自审核过的固定题库；文字判词可搭配 AI 合成女声。首次点击「开启自然人声」或「听题」，开启后自动播报新回应及结果；录音、关声音或离开页面时立即停止。

当前先交付微信小程序，H5 作为后续可选入口。本地浏览器已接入真实文字 AI、短录音转写和自然女声播报，用于验证同一批小程序页面；尚未公开上线。微信语音练习须部署最新云函数、填写账号配置后真机验证。正式 H5 还需接入真实用户身份、后端鉴权、录音权限和部署，不能直接将本地测试服务公开。

好友房在单人试玩通过后与排行榜一起实现。界面采用顶部题目与轮次、共享消息记录、底部明确操作入口；讨论不调用 AI，正式提问和猜底由当前玩家确认后提交。具体同步和交接规则见[验收清单](docs/ACCEPTANCE.md)。

## 先运行本地检查

需要 Node.js 20 或更高版本。从仓库根目录执行：

```sh
npm test
npm run check
npm run preflight
npm run preview
```

`preview` 默认走真实服务。在仓库根目录创建被 Git 忽略的 `.env.preview.local`（权限建议 600），只在该文件填入密钥：

```dotenv
DASHSCOPE_API_KEY=在本机填写北京地域的Key
GAME_ENABLED=true
LLM_MODEL=qwen-plus
ASR_MODEL=qwen3-asr-flash
TTS_MODEL=qwen3-tts-flash
TTS_VOICE=Serena
```

运行后打开 <http://127.0.0.1:18875/>，从「第一次玩？跟着做一遍」开始。保存配置后可重新检查连接；不会把 Key 放到浏览器。每次确认提问/猜底会计费，查看提示和查询原结果不重复调用模型。开发服务仅绑定本机，内存保存会话；重启会清空会话与当次运行计量，不是账单硬上限。此服务不接微信内容安全审核，仅供开发者本机联调；上线使用云函数的鉴权、审核和持久配额。

仅检查布局时显式用 `npm run preview:fixture`；页面会标明固定裁判。未配置真实模型绝不自动切到测试答案。`npm test` 全部使用隔离替身，不产生外呼。真实回归另用 `npm run eval:ai`（练习题 24 次）或 `npm run eval:ai -- --full`（共 96 次）。该脚本直接调用模型，不走游戏配额；结果存于被忽略的 `.preview-data/`，仅在需要复测时运行。

2026-11-07：优化模糊指代和相关性判断后，`qwen-plus` 非思考模式的 96 条固定样本全部符合预期，其中猜底 16/16。详见[真实验证记录](docs/IMPLEMENTATION.md)。这不是整体产品准确率，也不代替微信真机录音验收。

没有真实 AppID、云环境时，可先用本机 Key 验证文字 AI，微信录音和云端权限仍无法完成联调。未配置或未显式启用时应展示待配置状态，生产入口不会自动伪造 AI 答案。

## 导入微信开发者工具

1. 先复制 `miniprogram/config.example.js` 为 `miniprogram/config.local.js`（可先保持空），再使用[官方稳定版工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入仓库根目录，填写本人账号的真实 AppID。
2. 从该 AppID 项目的「云开发」入口创建或关联环境。
3. 在被 Git 忽略的 `miniprogram/config.local.js` 填写云环境 ID。
4. 按[部署说明](docs/DEPLOY.md)创建私有集合、配置云存储并部署 `game` 云函数。
5. 百炼密钥只放云端受控配置。先保持 `GAME_ENABLED=false`，完成真实权限、隐私及内容处理检查后再开启调用。

账号注册、扫码和充值由用户完成；代码、配置协助、题库和测试由开发方处理。不要在聊天、前端或 Git 中提交 API Key、AppSecret 或阿里云主账号 AccessKey。

## 架构

```text
miniprogram/                   微信原生页面、录音、草稿、受控公开数据
cloudfunctions/game/           单个 game 云函数及服务端私有题库
  data/puzzles.js              三道正式题及人工测试预期
  data/tutorial.js             独立练习题的私有事实和测试预期
  lib/                        服务、存储、模型与音频适配
tests/                         无真实外呼的自动测试
docs/                          接口、部署、内容与验收说明
```

主链路为录音上传、同步 ASR、文字确认、服务端判题、显示文字和可选人声播报。浏览器使用锁定版本的 MIT 开源 [Recorder](https://github.com/xiangyuecn/Recorder) 录制单声道 16kHz WAV；微信原生录音仍使用 MP3。客户端不直连模型、不保存汤底。数据库由云函数访问，录音存储采用仅创建者可读写的安全规则；服务端另行校验已登记文件归属和实际音频，凭管理权限下载及删除。

## 费用与验收边界

基准假设每局 32 次调用，每段录音平均 6 秒，每次模型输入 2,000、输出 50 token。按北京地域 `qwen3-asr-flash` 0.00022 元/秒、`qwen-plus` 非思考模式输入 0.8 元/百万 token 与输出 2 元/百万 token 测算：

```text
基础调用费  192 × 0.00022 + 32 × (2000 × 0.8 + 50 × 2) ÷ 1000000
          = 0.09664 元/局
加30%余量 = 0.125632 元/局
```

上述为识别和裁判费用。新增自然人声按 `qwen3-tts-flash` 北京价格 0.8 元/万字符测算：假设每局读题、判词和揭晓合计 800 字且全部重新合成，增加 0.064 元；总基础费用 0.16064 元，加 30% 余量约 0.2088 元。全语音版暂按每局 0.21 至 0.25 元预留，云资源另算。重复内容会复用合成结果，但冷启动、缓存过期或重启可能重新合成，预算不预扣缓存收益。参见[人声合成价格](https://help.aliyun.com/zh/model-studio/qwen3-tts-flash)。100 元是小规模试玩预算，不是整月账单硬上限。长局、更多录音、重试和更换模型会改变费用，免费额度不计入长期预算。价格核查日期为 2026-11-07，运营时继续核对[语音价格](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash)和[文字模型价格](https://help.aliyun.com/zh/model-studio/qwen-plus)。

3 至 5 秒是正常网络下的系统等待目标，不是实测或 SLA。真实录音、模型问答、跨端表现和平台权限按[验收清单](docs/ACCEPTANCE.md)逐项记录；未测项不能写成已达标。

## 本机语音试玩

打开 Chrome 等支持麦克风的浏览器，先同意语音用途说明和麦克风权限，再按住说话、松手转写。首次授权时如果已经松手，再按住一次开始录音。文字核对后才提交 AI。人声默认关闭，点「听题」或「开启自然人声」后开启；可随时关闭或重播。若浏览器拦截自动播放，点击重播；若麦克风被拒，在地址栏网站权限中开启，打字始终可用。

本机录音只保存在内存，成功识别或取消后清理；未完成文件最多保留 10 分钟并按分钟清理，服务重启后消失。缓存的主持音频只含固定故事和主持判词，不朗读玩家任意输入。进行中的游戏不能获取汤底声音。微信真机和嵌入浏览器的系统权限仍需各自测试。
