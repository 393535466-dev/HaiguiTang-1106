# 首版执行与验证记录

这是 2026-11-06 的 0.1.0 调试版历史记录。当前试玩范围以 [README](../README.md) 为准。

## 已实现

- 微信原生首页、单人推理页与隐私说明页，三道固定原创题。
- 按住录音、松手转写、编辑确认后判题；直接文字提问、完整猜底、三级提示、揭底、清空、恢复与反馈。
- 九条离线生成的固定判词语音，约500KB，无逐次TTS费用。
- 服务端身份隔离、私有汤底、请求幂等、原子配额、未知结果查询、显式重试和过期清理。
- 北京地域百炼ASR/裁判适配、微信文字安全检查、生产调用默认关闭。
- 不依赖账号的本地界面预览；常驻注明测试裁判，无真实AI/ASR调用。

## 本地已验证

在当前 Mac、Node.js 24.22.1 执行：

| 检查 | 结果 |
|---|---|
| `npm test` | 56项通过，0失败；无真实模型外呼 |
| `npm run check` | 38个JS/JSON文件、全部页面入口及完整汤底/Key静态扫描通过 |
| `python3 scripts/generate-audio.py --verify-only` | 九条音频格式、时长、非静音、未削波、SHA256通过 |
| 浏览器操作实际小程序页面/控制器 | 首页→开局→标准提问→提示→同义猜底通过→清空回首页 |
| 未配置模式 | 显示配置提示、题目开局按钮禁用 |

重要测试覆盖：499配额并发边界、重复ID不重复外呼、HTTP5xx/超时结果未知、旧结果不覆盖新请求或草稿、清空后不重建会话、录音实际帧时长/流式下载大小、孤立文件删除失败保留、7天本机正文清理及30天计量清理。SDK事务与存储接口已对照安装版本源码核验。
