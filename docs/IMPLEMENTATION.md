## 2026-11-07 提问中的猜底意图误报服务失败

用户在「没看的电影」提问模式输入「因为他是卖票的。」时，模型实际返回 `intent=answer_guess`、`answer=uncertain`。程序先校验提问答案枚举，再处理意图，导致这一可处理的猜底意图被误判为非法输出，显示笼统的「服务未能完成」。已复现该错误。

修复为先校验并处理已识别的非提问意图，统一返回带具体原因的澄清；猜底意图提示切到「我猜到了」。模型随附的猜底判词不会使本次提问判成功或提前揭底。正常是非问句仍严格校验提问枚举；未知意图及非法回答继续拒收。其他真实的模型格式异常、上游拒绝请求现在分别给出明确提示，保留草稿；服务端记录私有错误码，不保存或展示供应商原始错误内容，不自动重试付费请求。

本地 90 项测试与 61 个 JS/JSON 文件检查通过。真实模型与浏览器复测原句得到 `clarify/guess`，不扣有效提问次数；随后问「她进影厅看电影了吗？」正常返回「不是」。已有本机会话在应用修复时保留，无需重开。

## 2026-11-07 语音输入、自然女声与判题优化

本机浏览器接通实际录音 → 服务端上传 → 百炼识别 → 可编辑草稿 → 玩家确认 → AI 判题。采用锁定版本的 MIT 开源 Recorder 录制 16kHz 单声道 WAV，来源与许可见[第三方说明](THIRD_PARTY.md)。录音需同意用途并授权；取消不上传，静音在本机服务端拦截，识别完成不自动发送问题。保持中文输入法修复，并修正按住录音期间页面重绘造成松手事件丢失的问题。

录音文件只接受服务端事先登记的当前会话路径；校验实际 WAV 格式、长度、时长及音量。浏览器录音保存在内存，成功识别或主动取消即清理；遗留文件十分钟到期、按分钟清理。微信端保持原生 MP3 链路。

主持声使用 `qwen3-tts-flash`、温和女声 `Serena`。玩家点击「听题」或「开启自然人声」后，可播报题目、新判词和结束时的完整答案；可关闭或重播。录音、切页或关闭声音会停止播报，晚到音频不重新播放。服务端只合成固定题目与审核后的主持词，不接受任意客户端朗读文本；未结束的局不能取得答案音频。相同文本合并并发请求、缓存有效音频地址；失败不自动重复付费调用。音频加载失败不阻断文字游戏。

判题补充事件指代和相关性问法。人物明确但「这件事」无唯一指向时，要求补充；询问某细节是否影响解释时，判断相关性。额外口语与干扰测试发现，模型在猜底环节拒绝干扰指令时可能返回提问用的 `clarify`。现在将这一明确的澄清状态呈现为猜底的 `uncertain`，不计失败猜底、不判成功；其他非法枚举仍拒收。尝试扩大猜底提示约束时出现部分正确回答被过度澄清的回归，已撤回该提示改动。没有自动重试付费请求。

## 2026-11-07 中文输入修复

复现了输入「小周」却留下逐段拼音的问题：本机网页每次 `input` 都重建输入框，打断输入法组合。现在在中文选字期间保留原输入框，拼音候选不写入草稿；确认或取消选字后同步最终文字并恢复页面更新，异步响应与窗口变化也不会在选字中途重建输入框。修复位于浏览器预览层，覆盖练习与正式游戏的提问、猜底输入框。

新增 `tests/browser/preview-input.js`，使用 Chromium 原生 IME 协议逐步组合；修复前实际复现 `xxixiaxiaoxiaozxiaozhxiaozhoxiaozhou小周`，修复后为「小周」，字数 2。四种输入场景及连续选字、选择替换、取消、混合输入、删除、插入与异步重绘均通过。测试使用独立固定裁判，不产生真实模型费用。已打开的本机页面需刷新加载修复。

## 2026-11-07 真实 AI 接入

练习与正式游戏已复用真实服务端裁判。自由输入直接送模型，不再匹配预设句子。默认选用 `qwen-plus` 非思考模式；密钥保存在 Git 忽略的本机 `.env.preview.local`，权限 600，不进入前端、仓库或接口响应。微信云端尚未部署，不能把本机配置视为手机端可用。

服务端增加独立、1 小时有效的 `startTutorial` 会话。私有练习题及通关标准迁至服务端；前端只取得汤面、已解锁提示和结束后的汤底。练习和正式局共享调用配额，不改动玩家的原局。模型先返回意图，再返回判词；开放问法等意图强制转为澄清。猜底按关键因果判断，接受简短同义表达，缺少因果不算通过。题库的未设定细节与已知无关细节分别维护。

配置缺失在入口提示；发送中显示处理状态。超时先查原请求，主动重试需确认可能再次计费，并撤销原请求写回资格。会话失效可重新连接；迟到结果不覆盖新草稿，处理中的旧消息不冒充新答案。本机预览默认真实 AI，只有显式 `npm run preview:fixture` 使用固定测试答案。
