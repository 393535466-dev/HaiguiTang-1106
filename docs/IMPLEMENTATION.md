# 首版执行与验证记录

当前试玩范围以 [README](../README.md) 为准。后面的「玩家输入补充」及更早章节均为历史状态；当前文字判题已接入真实模型。

## 2026-11-07 中文输入修复

复现了输入「小周」却留下逐段拼音的问题：本机网页每次 `input` 都重建输入框，打断输入法组合。现在在中文选字期间保留原输入框，拼音候选不写入草稿；确认或取消选字后同步最终文字并恢复页面更新，异步响应与窗口变化也不会在选字中途重建输入框。修复位于浏览器预览层，覆盖练习与正式游戏的提问、猜底输入框。

新增 `tests/browser/preview-input.js`，使用 Chromium 原生 IME 协议逐步组合；修复前实际复现 `xxixiaxiaoxiaozxiaozhxiaozhoxiaozhou小周`，修复后为「小周」，字数 2。四种输入场景及连续选字、选择替换、取消、混合输入、删除、插入与异步重绘均通过。测试使用独立固定裁判，不产生真实模型费用。已打开的本机页面需刷新加载修复。

## 2026-11-07 真实 AI 接入

练习与正式游戏已复用真实服务端裁判。自由输入直接送模型，不再匹配预设句子。默认选用 `qwen-plus` 非思考模式；密钥保存在 Git 忽略的本机 `.env.preview.local`，权限 600，不进入前端、仓库或接口响应。微信云端尚未部署，不能把本机配置视为手机端可用。

服务端增加独立、1 小时有效的 `startTutorial` 会话。私有练习题及通关标准迁至服务端；前端只取得汤面、已解锁提示和结束后的汤底。练习和正式局共享调用配额，不改动玩家的原局。模型先返回意图，再返回判词；开放问法等意图强制转为澄清。猜底按关键因果判断，接受简短同义表达，缺少因果不算通过。题库的未设定细节与已知无关细节分别维护。

配置缺失在入口提示；发送中显示处理状态。超时先查原请求，主动重试需确认可能再次计费，并撤销原请求写回资格。会话失效可重新连接；迟到结果不覆盖新草稿，处理中的旧消息不冒充新答案。本机预览默认真实 AI，只有显式 `npm run preview:fixture` 使用固定测试答案。

### 实际验证

2026-11-07 20:58（北京时间）的完整回归使用北京兼容接口、`qwen-plus`、温度 0、JSON 输出、非思考模式，四题各 20 条提问和 4 条猜底。按当前提示词跑一次，没有自动重试失败样本。

| 题目 | 提问 | 猜底 | 合计 |
|---|---|---|---|
| 雨中的小周（练习） | 20/20 | 4/4 | 24/24 |
| 没看的电影 | 19/20 | 4/4 | 23/24 |
| 图书馆里的大喊 | 20/20 | 4/4 | 24/24 |
| 没有人的合照 | 20/20 | 4/4 | 24/24 |
| 合计 | 79/80 | 16/16 | 95/96 |

本轮输入 90,074 token，输出 1,094 token；模型请求耗时中位数 576ms、P95 978ms、最长 1,246ms。这些是本机文字请求耗时，不包括微信冷启动、录音、上传、识别和玩家确认。按 README 单价估算本轮文字调用约 0.0743 元，以平台账单为准；早期调参调用另计。原始逐条结果保存在本机被 Git 忽略的 `.preview-data/ai-eval-qwen-plus.json`。

唯一未符合预期的固定样本是「他知道这件事吗？」：人工预期 `clarify`，模型返回 `unspecified`。此处仍应要求说明「这件事」是什么；保留该失败记录，后续按真实试玩收集更丰富的指代样本。初始 `qwen-flash` + 初始提示词为 86/96，之后同时调整了模型、提示词和题库字段，不能把改进全部归因于换模型，也不能把固定样本通过率当作整体准确率。

Chrome 另测了一条连续流程，5 次真实裁判调用全部符合预期：新口语问法「所以他出去那会儿其实已经不下了，对吧？」→ 是；「他为什么没被淋到？」→ 澄清；「那他是不是在雨里穿雨衣走的？」→ 不是；雨衣猜底 → 方向不对；「等雨不下了，他才迈出家门。」→ 猜中。输入、显式发送、提示、揭晓、返回选题及原游戏草稿保留均通过。检查了未配置入口、320px 宽度和浏览器不模拟语音。

本地 `npm test` 81 项通过，0 失败；`npm run check` 检查 50 个 JS/JSON 文件、全部页面入口以及客户端完整汤底/Key 扫描通过。测试覆盖配置门槛、真实 provider 协议、公开响应不含密钥/汤底、私有路径拒绝访问、跨站请求拒绝、请求去重、失效重连、主动重试和晚到结果。

### 当前边界

本机文字 AI 可试玩。真实微信 AppID、云开发环境仍待准备；微信录音转写、真实麦克风权限、云端内容安全、跨用户存储权限与清理任务仍待部署及手机验证。每题连续 20 轮和 30 条录音验收未完成。好友房与排行榜仍按约定，单人真机试玩通过后一起实施。

更换为 `qwen-plus` 后，以每局 32 次、每次 2,000 输入/50 输出 token、每段录音 6 秒测算，文字约 0.0544 元，语音约 0.04224 元；加 30% 余量约 0.1256 元。暂按每局 0.13～0.16 元预留，云资源另算。练习调用、长局及主动重试另外计量。
