# 微信单人语音版部署

本项目的目标是微信内单人语音体验版。当前原生小程序页面方案需要先结合真实账号的可用类目、录音能力和体验资格核对；若平台要求使用小游戏运行时，应先调整前端接入，不用不匹配的类目提交审核。

没有真实 AppID、云环境和模型密钥时，可以进行源码检查、隔离的服务端测试与界面预览。这些结果不代表微信真机录音、真实模型准确率或 3 至 5 秒等待目标已经通过。

## 1 用户先准备账号

- [微信公众平台](https://mp.weixin.qq.com/)：已有账号先登录，保存真实 AppID，管理员能扫码。
- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)：安装适合 Mac 芯片的稳定版，管理员或已加入开发者的微信扫码登录。
- [百炼 API Key 官方指引](https://help.aliyun.com/zh/model-studio/get-api-key)：开通北京地域账号并创建 API Key，按需小额充值。
- 至少一部真实手机；有条件增加另一系统的手机。3 至 5 位朋友在版本可玩后再约。

用户负责注册、实名、扫码和充值；环境部署、接口配置、题库及测试由开发方处理。AppID 和环境 ID 可以交接，API Key、微信 AppSecret 和阿里云主账号 AccessKey 不发到聊天、不放前端、不提交 Git。

## 2 导入项目并关联云环境

1. 首次编译前，将 `miniprogram/config.example.js` 复制为 `miniprogram/config.local.js`，可先保持空，避免原生编译器因缺少引用文件报错。再在开发者工具中导入仓库根目录，填入当前账号的真实 AppID。代码中的占位 AppID 只用于导入说明，不是可发布账号。
2. 参考 [CloudBase 创建指引](https://docs.cloudbase.net/quick-start/create-env)，从当前 AppID 项目的「云开发」入口开通环境。优先使用此入口，使环境自动关联当前小程序。
3. 如使用已有腾讯云环境，先按官方指引核对账号绑定和环境转换，不直接选一个未关联的 Web 环境。
4. 在已复制、本机忽略的 `miniprogram/config.local.js` 填入：

   ```js
   module.exports = {
     cloudEnv: '你的微信云环境 ID',
     functionName: 'game'
   }
   ```

5. 核对项目配置的 `miniprogramRoot` 为 `miniprogram/`，`cloudfunctionRoot` 为 `cloudfunctions/`。首次保留最少环境，不购买高档年付套餐。

## 3 创建私有数据和存储

在云开发数据库创建以下五个集合：

| 集合 | 用途 |
|---|---|
| `sessions` | 用户归属、题目版本、游戏状态和活动请求 |
| `requests` | 提交快照、派发状态和恢复查询 |
| `usage` | 按日用户及全局计量 |
| `uploads` | 服务端登记的录音归属和清理期限 |
| `feedback` | 错误判题和题目反馈类型，不收自由文本 |

五个集合的客户端读写均关闭，由云函数访问。小程序只能通过 `game` 云函数取得自己的公开会话，不直接读数据库。题库放在 `cloudfunctions/game/data/puzzles.js`，不上传到小程序的 public 或 data 目录。

云存储设置为仅创建者可读写（默认安全规则），禁止所有用户可读写；云函数凭管理员权限下载和删除。文件路径中的用户散列前缀不代替存储权限，也不能直接当作openid规则。上传必须先调用 `registerUpload`，再使用服务端返回的 `cloudPath`；服务端再次校验上传归属、实际格式、大小及音频时长。用两名测试用户验证不能读取对方的录音或会话。

## 4 配置并部署云函数

在微信云开发选择受支持的 Node.js 20 或更高运行时，部署 `cloudfunctions/game`，函数名保持 `game`，使用「云端安装依赖」。服务端锁定 `wx-server-sdk` 版本，具体见 `package-lock.json`。

将 `cloudfunctions/game/.env.example` 作为控制台填写参考。它不会由小程序加载，也不会自动把本机环境变量同步到云端。

| 云端环境变量 | 填写内容 |
|---|---|
| `DASHSCOPE_API_KEY` | 北京地域的百炼 API Key，由用户自行写入云端受控配置 |
| `DASHSCOPE_BASE_URL` | 默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`；使用业务空间域名时按该地域官方地址填写 |
| `LLM_MODEL` | `qwen-flash`，真实回归不通过时再评估替换 |
| `ASR_MODEL` | `qwen3-asr-flash`，同步短录音识别 |
| `GAME_ENABLED` | 首次保持 `false`；完成权限、内容处理和基础测试后才显式设为 `true` |
| `DAILY_USER_LIMIT` | 初期 `100`，每名用户每类外呼每日上限 |
| `DAILY_GLOBAL_LIMIT` | 初期 `500`，全环境每类外呼每日上限 |

API Key 地域、模型和服务地址必须一致。在云函数控制台将执行超时设为 60 秒，给上游 30 秒截止后的状态写回留出时间；若控制台不支持这一设置，先核对运行时和环境能力。仓库 `config.json` 用于声明接口权限与定时器，不会自动设置执行超时。应用超时或用户退出不会保证厂商取消调用或不计费。

生产入口不允许隐式使用测试 provider。未配置或未启用时，界面应明确显示待配置，不返回伪造的 AI 判词。

## 5 核对录音与内容处理

1. 在实际小程序后台完成与录音、第三方识别及数据用途相符的隐私说明；首次录音前处理隐私同意和麦克风权限。
2. 云函数使用微信内容安全接口检查玩家输入和识别文字；裁判输出只接受固定枚举，题库汤底和提示由人工审核。当前账号的接口权限、服务场景和真机行为要实际验证；接口不可用时应显示 `CONTENT_CHECK_UNAVAILABLE`，不绕过检查。
3. 真机录制不超过 20 秒的 MP3。识别后先显示可修改文字，玩家确认后才送裁判。拒绝录音仍可使用文字输入。
4. 固定判词播放仓库内预录音频，不逐次付费合成汤面、汤底或提示。
5. 查看 `status` 返回的 `textReady`、`voiceReady` 和配置提示，再进行少量真实调用。

## 6 配置清理并小范围开放

使用 `cloudfunctions/game/config.json` 中的定时器配置部署清理触发器：名称 `cleanup-hourly`，表达式 `0 0 * * * * *`（每小时整点）。清理仅允许无客户端OPENID且带指定TriggerName的可信Timer触发上下文执行；不要从小程序端调用 `cleanup`，也不要把接口公开成管理后门。

清理边界：成功识别后的录音删除；其他录音登记后23小时到期，为小时任务预留窗口，正常运行下目标24小时内清理。会话与含正文的请求快照7天到期作废，撤销旧请求写回，下一轮小时任务删除正文；去标识计量30天后由小时任务清理。本机草稿与待确认请求在下次打开时清理过期数据。用测试数据验证实际删除结果，不仅检查定时器创建成功。若清理结果含 `pendingUploads` 或失败项，说明仍有孤立文件等待处理；需核对当前云环境的上传元数据API与管理权限，不能据此声称文件已删除。

按 [验收清单](ACCEPTANCE.md) 完成一部真机的完整流程，再增加体验成员。缺少某种手机时标记该端未测。100 元是初期小规模运行预算，免费额度变化、长局、更多录音及云资源超额都可能改变费用。

## 常见阻塞

| 表现 | 优先检查 |
|---|---|
| 看不到云环境 | 开发者工具与云环境是否关联同一个真实 AppID 和账号 |
| `CONFIG_REQUIRED` 或未启用 | 云函数环境变量、Key 所属地域、`GAME_ENABLED`、重新部署状态 |
| 内容检查不可用 | 实际账号权限、内容接口场景与服务端错误码；保持关闭外呼排查 |
| 录音无文字 | 隐私和麦克风授权、MP3 实际格式、大小、长度及 ASR 权限 |
| 请求显示结果未知 | 先查原 requestId，不能自动重发；主动新尝试可能再次计费 |
| 同一请求重复出现 | 不应刷新页面或生成新 ID 规避；保留请求编号给开发方排查 |

公开发布需要另行核对类目、隐私、审核及体验资格，不能把开发者工具中的预览成功当作已获公开发布许可。
