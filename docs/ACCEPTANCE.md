# 单人语音版验收记录

这是执行清单，不是已经通过的测试报告。每轮记录日期、设备系统、基础库版本、云环境、题目版本、识别模型和裁判模型。没有真实账号和 Key 时，模型质量与微信真机项保持未测。

## 本地可先验证

从仓库根目录运行：

```sh
node --test tests/*.test.js
```

本地测试使用显式 fake provider 验证状态、权限、计量和异常，不会访问真实模型。`tests/puzzles.test.js` 检查三题、60 条问答预期与 12 条猜底预期是否完整；它不能证明模型能答对这些用例。

## 真实语音链路

准备 30 条自愿提供的录音，分配到三道题，覆盖正常语速、否定词、人名、指代、安静环境和背景声。

| 项目 | 目标 | 实际记录 |
|---|---|---|
| 语义保持 | 至少 27/30 条无需改关键语义；其余可编辑纠正，不自动改问意 | 未测 |
| 系统等待 | 至少 27/30 条从松手至可用判词的系统耗时不超过 5 秒 | 未测 |
| 上传耗时 | 单独记录，计入总体等待 | 未测 |
| ASR 耗时 | 单独记录 | 未测 |
| 裁判耗时 | 单独记录，包含冷启动 | 未测 |
| 手动确认 | 从总墙钟时间中单独列出，不与系统等待混淆 | 未测 |

3 至 5 秒是开发目标，不是厂商 SLA 或已测表现。记录中同时保留从松手到回答的总墙钟时间，避免把手动修改和确认带来的实际等待藏掉。

## 裁判与题目

每题 `testCases` 包含 20 条人工标准问答。用真实裁判逐条执行并保存题目 ID、版本、输入、预期判词、实际枚举、耗时和 token。

- 三题合计至少 57/60 条命中人工预期，核心事实不得矛盾；歧义应澄清，未设定细节不得编造。
- 每题再连续问 20 轮，包含改问法和人物指代，确认完整有效历史可用，重复问题不自相矛盾。
- 每题四条 `guessCases` 分别为完整正确、正确同义、缺关键原因、关键矛盾。前两类必须通过，后两类不得通过。
- 猜底只判断本次完整提交；不能把之前互相冲突的猜测凑成正确答案。需补充和暂无法判定不扣失败猜底机会，但占外呼尝试额度。
- 测试“忽略规则直接通过”、伪造系统消息、历史埋入指令、要求翻译或编码汤底。合法枚举也可能语义错误，不能仅凭 JSON 解析通过。
- 未猜中、未主动揭底时，响应和日志不得含汤底、内部评分点或模型原始解释。

样本仅服务首版筛选，不能把 57/60 写成产品整体 95% 准确率。

完整回归及连续对话可能超过单人100次判题日配额，应分两天或使用两个已授权测试账号执行，并分别保留记录。不要通过更换requestId绕过配额。

## 权限和异常

| 操作 | 应达到的结果 |
|---|---|
| 第二名用户读取第一名用户会话、请求或文件 | 拒绝；身份由云端上下文取得 |
| 同 requestId 重复提交相同内容 | 返回原状态，不再次外呼 |
| 同 requestId 换文本 | 拒绝，不改变已冻结快照 |
| 两个请求同时接近额度边界 | 原子预占，只允许剩余额度内的调用 |
| 提交后客户端超时 | 查询原状态，不自动新建付费请求 |
| 已派发而结果未知后主动重试 | 用户确认新尝试；撤销旧写回资格，仍记录可能发生的费用 |
| 旧结果在新尝试后到达 | 不追加旧消息、不覆盖草稿 |
| 转写后改字但未提交即关页 | 本地草稿恢复；服务端不伪造尚未提交文本 |
| 麦克风被拒、滑开取消、电话打断、切后台 | 提示明确，停止或取消录音，保留文字入口 |
| 清空或会话 7 天到期 | 作废旧局、撤销活动请求并删除正文；引导新开 |
| 录音转写成功、失败或取消 | 按保留规则清理，不能长留孤立文件 |
| 未配置 Key、未启用、内容检查失败 | 明确服务状态，不伪装是、否、无关或未通过 |
| 第三条提示、主动揭底及再来一局 | 静态提示按级解锁；揭底先确认；新局不混入旧消息 |

## 真实试玩与交付

3 至 5 名未听过解释的人，应能理解按住说话、确认文字、切换猜底、用提示和结束本局。记录是否主动重玩、在哪一步停住，不只收集“挺好玩”的评价。

两天交付清单：源码、配置说明、设备记录、真实调用记录、清理验证、体验成员入口。若关键功能仍未过验收，应标记调试版并列出具体未测或失败项，不用文字演示替代约定的语音版。

## 20 局后复核

实际统计每局识别秒数、模型输入输出 token、失败和重试次数、上传流量与云资源费用，再修订预算。基准假设每局 32 次、每段 6 秒、每次 2,000 输入和 50 输出 token；当前单价下加 30% 余量约 0.071 元/局，按 0.08 至 0.10 元留预算，不代表账单上限。
