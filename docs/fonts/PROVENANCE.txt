Coverage and implementation detail
- Both fonts have outlines for CHOOSE YOUR TABLE.
- PinRu has outlines for all characters in 你看到的未必是真相进入游戏海龟汤今晚怎么探个究竟.
- Aoyagi lacks actual outlines for 你进戏龟汤晚么 in that test string.
- PinRu covers all 528 distinct Han characters found in the current miniprogram/pages/**/*.wxml and **/*.js source at inspection time.
- Aoyagi has 12,204 Han cmap entries but only 6,356 Han characters with nonempty outlines. Many entries map to empty glyphs, so a plain font-family fallback chain alone is insufficient; a mapped empty glyph can render blank rather than fall back.
- aoyagi-nonempty-unicode-range.css contains a CSS unicode-range declaration selecting only nonempty outline codepoints plus intentional whitespace. This changes CSS character eligibility only and does not alter the original font. Apply it inside the Aoyagi @font-face block, with PinRu next in the family stack.
- font-coverage.json contains exact hashes, byte sizes, missing-character lists, and tests.
- Full original TTFs total approximately 10.46 MB decimal; copying raw fonts into a WeChat mini-program package may exceed its asset/package constraints. Loading strategy and actual target browser/mini-program rendering need parent-task validation.
